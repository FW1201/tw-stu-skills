# 方法與來源

- [PRISMA 2020](https://www.prisma-statement.org/prisma-2020)：報告規範，非檢索完成保證。
- [主題分析作者說明](https://www.thematicanalysis.net/faqs/)：反身性、codebook、coding reliability 取向分流。
- [SciPy t檢定](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html)：獨立／Welch、CI與實際資料。
- [statsmodels power](https://www.statsmodels.org/stable/generated/statsmodels.stats.power.TTestIndPower.solve_power.html)：明示設計與效果量前提。
- [Crossref metadata](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)：查無不等於不存在；出版者與中文機構典藏仍需選用。
- [CAST UDL](https://udlguidelines.cast.org/more/downloads/)：材料與支援的可及性選擇。

原套組整合的研究寫作、方法及108課綱情境保留為領域背景；本版逐項重寫流程，沒有以缺檔的外部技能資源作必要依賴。目標期刊、學校與招生規則須於任務當下查官方版本。
